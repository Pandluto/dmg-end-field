## 最终产品边界

1.8 LTS 不再拆成“桌面 LTS”和“线上精简版”，而是直接交付一个桌面浏览器 Web LTS：

- 不适配手机；
- 不提供账号、云同步或服务端用户数据库；
- 使用客户端密码 `zmd` 与 30 天浏览器租约做本地部署门禁；
- 私人数据进入 SQLite WASM/OPFS；
- 官方 JSON 与图片在用户首次确认后下载并校验；
- 同一浏览器只允许一个标签页写入，可显式接管；
- 页面重组为首次进入、开始、排轴工作区、数据工作区和设置；
- 当前只做本地部署，不推送 GitHub Pages。

| Timeline | 文档、快照、Work Node、patch、commit、checkout、审计和存档全部进入浏览器 repository |

| UI | 新侧栏、开始页、数据页、设置页、访问门禁、占用/接管页和工作区命名模态框 |

## 最终删除

- 整个 `electron/`：主进程、preload、SQLite repository、数据管理、web host、renderer transport、签名配置与安装包图标；
- `public/shell/`；
- localhost bridge、desktop runtime 类型与 renderer capability；
- 旧 SQLite/AppData 迁移、备份恢复、桌面数据 Release、catalog、图片 Release 和 notarize 脚本；
- Electron/electron-builder/concurrently/wait-on 依赖与全部桌面构建命令；
- Windows/macOS 安装包 Release workflow；
- 已被 Web 数据生命周期取代的桌面数据管理 Spec、Shell 图片 Spec、历史
  Worktree tasks，以及 Timeline 的桌面迁移任务/兼容清单。

这些删除均保留在 Git 历史中，可从本分支收口前提交恢复；未改写历史。

## 数据保护

- 没有读取、修改、清理或提交 `data/sharedata/**`。
- `public/packages/*.zip` 被忽略；本机下载的图片 sidecar 不进入 Git。
- 不探测或迁移用户 AppData 与旧桌面 SQLite。
- 清理浏览器站点数据会删除 Web LTS 私人数据，设置页提供完整 SQLite 导出。
