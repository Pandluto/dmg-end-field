# 打包版快速上手

## 入口

- `打开浏览器 Web`：进入主工作台。
- Shell `数据`：保存、下载、应用完整数据包。
- Shell `图片`：检查、下载与切换图片资源。

## 应用数据

1. 在 Local Data 或 Share Data 中选择完整数据包。
2. 点击“应用数据”，选择分组；需要时先备份当前数据。
3. 回到 Web 刷新。

网络下载只进入 Share Data，不自动覆盖当前页面或排轴。

## 排轴与恢复

1. 选择最多四名干员并进入排轴。
2. 从右侧拖技能到左侧时间轴。
3. 用底部“保存 / 恢复 / 分享”管理方案。
4. 本地/共享存档会转换为新的 SQLite 工作区；SQLite 工作区可直接切换。
5. Work Node 节点树可保存同一排轴的分支方案。

## 配置与计算

- `角色配置`：等级、潜能、技能、武器与装备。
- 技能详情：加入/移除 Buff、调层数、抗性与 Hit。
- `BUFF批量操作`：对多个节点批量增加、删除或编辑 Buff。
- `计算` 与报表入口：查看伤害过程并导出结果。

## 自定义资料与图片

底部可进入干员、Buff、武器、装备与图片编辑页。修改资料后回主界面刷新或重新选择干员。
