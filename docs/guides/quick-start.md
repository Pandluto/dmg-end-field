# Web LTS 1.8 快速上手

## 第一次进入

1. 用桌面 Chrome 或 Edge 打开本地站点。
2. 阅读资料说明，点击“下载完整资料并开始”。
3. 等待 JSON 文件和图片完成校验。

应用不会读取旧桌面 SQLite，也不会创建账号或上传私人数据。

## 页面

- `开始`：查看最近工作区、快照和快捷入口。
- `排轴工作区`：选择最多四名干员，配置角色，编辑时间轴、Buff 与伤害报告。
- `数据工作区`：维护干员、Buff、武器、装备和浏览器图片库。
- `设置`：查看存储状态，导入/导出 SQLite，删除并重装官方资料。

## 排轴与恢复

1. 进入排轴工作区并选择队伍。
2. 把技能放到时间轴，调整 Hit、Buff、抗性与层数。
3. 首次保存时给工作区命名。
4. 用 Work Node 保存分支方案；revision/CAS 会拒绝过期覆盖。
5. 用本地存档或分享 JSON 流转单个方案；用设置页 SQLite 备份保存全部私人数据。

## 多标签页

同一浏览器只允许一个标签页写入。新标签页会显示“工作区已占用”，可以：

- 回到原标签页继续；
- 点击“在此标签页继续”显式接管。

接管后旧标签页会让出写权限。不要在多个浏览器配置中同时编辑同一份手工导入的备份。

## 数据与图片

- 官方资料可随时删除并重新下载，不会删除私人排轴。
- 导入图片写入浏览器 SQLite，可重命名、分目录或删除，并随完整数据库备份。
- 浏览器或操作系统清理站点数据时，OPFS 与 Cache Storage 都可能被删除；重要方案请定期导出。
