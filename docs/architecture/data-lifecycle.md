# 数据生命周期

## 三类数据

| 对象 | 内容 | 使用方式 |
| --- | --- | --- |
| SQLite 工作区 | 当前排轴、节点树、快照、checkout、审计 | 主界面直接编辑与恢复 |
| 本地/共享存档 | 单份排轴及节点树 | 转换为新的 SQLite 工作区 |
| Local Data / Share Data | 角色、武器、装备、Buff 与可选排轴存档 | 用户明确应用后投影到浏览器 |

## 写入方向

```text
网络 Release
  → 校验 manifest / 大小 / SHA-256 / ZIP 文件集合
  → 原子写入 Share Data
  → 用户选择“应用数据”
  → 浏览器资料投影 + 包内排轴导入共享存档

本地/共享排轴存档
  → 导入为新 SQLite 工作区
  → 用户切换 checkout 后显示
```

删除完整数据包、独立存档或 SQLite 工作区只影响明确选择的对象，不做级联删除。旧 JSON 与历史 storage key 仅用于兼容导入。
